Guia de componentes

Componentes de feedback do site, com as classes CSS de cada um, para reutilizar em novas páginas.

Badges (etiquetas)

Classe base .badge + variação. Usadas para categorizar os projetos e mostrar o status das vagas.

.badge--primaria .badge--sucesso .badge--aviso .badge--info .badge--neutro

Alertas

Classe base .alerta + variação. Mensagens fixas que ficam na página.

✓

Sucesso: seu cadastro foi recebido. (.alerta--sucesso)

✗

Erro: não foi possível enviar. Confira os campos em vermelho. (.alerta--erro)

⚠

Atenção: nunca pedimos doações por telefone. (.alerta--aviso)

ⓘ

Informação: seus dados são protegidos pela LGPD. (.alerta--info)

Toast e modal

O toast (.toast) aparece no canto da tela e some sozinho em 4 segundos. O modal usa a tag nativa <dialog> com a classe .modal.
